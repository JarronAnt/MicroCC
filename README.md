# MicroCC

MicroCC is a small C compiler written from scratch in modern C++.

The project is intended both as a compiler-learning project and as an
exploration of parsing, type systems, intermediate representations,
optimization, machine code generation, ABIs, and systems programming.

## Current Status

MicroCC is currently in Phase 1.

Supported C syntax:

```c
int main() {
    return 42;
}
